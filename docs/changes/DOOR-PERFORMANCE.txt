SAVED-DOOR PERFORMANCE UPDATE - 16 October 2026

Launch DuctTapeDoom-doors.exe or the updated DuctTapeDoom.exe.
The Duct Tape Doom renderer, resolution and graphics quality are retained.

CHANGES
Moving sectors invalidate only light-blocker cache entries whose original
query bounds intersect changed sector borders, instead of clearing all entries.
Surface-light merging uses hashed lookup while retaining accumulation order
and sorting the output to match the original implementation exactly.
Background lighting rebakes reuse a persistent pool of up to four workers,
instead of spawning half the hardware thread count for every phase. This
leaves CPU capacity for rendering while performing the same bake calculations.
The existing asynchronous bake/coalescing behavior remains.
